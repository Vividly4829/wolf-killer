# Wolf model

`wolf.glb` is adapted from [Wolf by Micket](https://opengameart.org/content/wolf-1),
an Eurasian wolf anatomy model and skeleton released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

The existing project asset was reused for this Godot game. Adaptations include
smoothed and optimized anatomy, amber eyes, black nose, grey coat shading, a
baked normal map, game scale, and connected-joint trot and attack animation.

The coat samples a small fur-only patch of CDmir's CC0
[Old Deer Male](https://opengameart.org/node/51387) diffuse texture. This patch
is mirrored, recolored, mapped in 3D, and baked into the wolf's own UV atlas.

The existing source files and conversion scripts are retained in the parent
project's `game/animal-source` and `game/build_wolf_asset.py`.
