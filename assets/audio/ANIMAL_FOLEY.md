# Species vocal foley

duck_hurt.wav, goose_hurt.wav, deer_hurt.wav, moose_hurt.wav and mink_hurt.wav are original synthesized vocal effects created for this project by tools/build_animal_pain.py. They use jittered pulse trains, resonant harmonics and short breath envelopes; they are not field recordings. No third-party recordings were used in these five files. Existing wolf, bear and human recordings retain their separate attribution files.

`wolf_hurt.wav` is a short, faded, normalized excerpt of the existing public-domain NPS Denali wolf recording (`wolf_howl_denali.mp3`); see the existing wolf audio attribution. Hit reactions use this separate clip so the ambient howl cooldown cannot silence injury feedback.
